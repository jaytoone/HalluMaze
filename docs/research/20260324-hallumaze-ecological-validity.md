# [research] HalluMaze 생태학적 타당성 확장 방향
**Date**: 2026-03-24

## 핵심 문제
미로 풀이는 실제 LLM 사용 환경(Q&A, 코드 생성, 의사결정)과 거리가 있음.
→ HalluMaze의 측정이 "일반 LLM 능력"이 아닌 "미로 특화 패턴"을 반영할 수 있다는 비판.

## 생태학적 타당성이 높은 이유 (강점)
- **closed-world 검증**: 이동 유효성을 deterministic으로 판단 — 외부 판사 불필요
- **mirage = "그럴듯한 거짓"**: 실세계 어디서나 존재하는 패턴
- **data leakage 방지**: seed 기반 절차적 생성
- **metacognition 분리 측정**: 오류 발생률이 아닌 오류 인식+수정 능력 측정

## 확장 방향: 미로 구조 유지 + 도메인 교체

| 도메인 | 미로 셀 | Mirage 벽 | 실세계 연결 |
|--------|---------|-----------|------------|
| Knowledge Graph | 개념 노드 | Deprecated 관계/잘못된 인용 | RAG, fact-checking |
| 코드 실행 경로 | 함수 노드 | 시그니처 맞지만 런타임 오류 | LLM 코드 에이전트 |
| 의사결정 트리 | 조건 분기 | 예외 케이스 규칙 | 의료/법률 추론 |
| 멀티턴 대화 | 대화 스텝 | 모순된 이전 발화 | 실제 챗봇 사용 |

## 원칙
```
생태학적 타당성 ↑ = 미로 구조(closed-world + mirage) 유지 + 도메인만 교체
                    ↕
             closed-world 검증 가능성은 반드시 보존
```

## 논문 활용
- HalluMaze v1: 공간 미로 (현재)
- HalluMaze v2 (제안): 도메인 확장판 — 동일 메트릭(MEI)으로 다양한 인지오류 측정
- NeurIPS 2026 후속 연구 또는 Section 7 Future Work로 활용
