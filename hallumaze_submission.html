HalluMaze: A Maze Navigation Benchmark for
LLM Metacognitive Error Recovery

Abstract

Overview

Measuring real-time metacognitive recovery — not just final-answer accuracy.

We introduce HalluMaze, a benchmark that measures large language model (LLM) metacognitive error recovery through maze navigation. Unlike existing hallucination benchmarks that evaluate final-answer accuracy, HalluMaze captures real-time error detection and corrective action by exposing models to navigable environments containing "mirage" walls — passages that appear blocked but are traversable. We evaluate 6 LLMs (MiniMax-M2.5, GLM-4.7, Llama-4-Scout, Llama-4-Maverick, Gemini-2.0-Flash-Lite, GPT-4o-mini) across n=30 seeds × 5×5 and 7×7 maze sizes. We introduce the Metacognitive Escape Index (MEI), grounded in Nelson & Narens' (1990) metamemory framework, which decomposes metacognitive performance into recovery rate (HRR), efficiency (ETR), awareness (AW), and error rate (HR). All tested LLMs score significantly below a random walk baseline (p<0.001 Bonferroni-corrected, d>1.2 for all), revealing a systematic deficit in real-time metacognitive recovery.

Method

Benchmark Design

Text-based maze navigation with injected mirage walls for controlled hallucination induction.

🧩
Task
Models navigate an N×N text maze from [0,0] to [N-1,N-1]. Each step: current position + wall state + 5-step history → output direction + confidence 0–100 + reasoning.
🌫️
Mirage Walls
2 mirage positions per maze, injected at generation time. A mirage reports wall=1 in the model's context but is actually passable. Environment contradiction is the detection signal.
📐
Maze Generation
Randomized DFS. Sizes: 5×5 (optimal 17 steps) and 7×7 (optimal 25 steps). Step budget: N²×3. n=30 independent seeds per condition.
🎲
Baselines
Random Walk: uniform random direction (HRR=1.0 by construction). A* and BFS: oracle algorithms with perfect world model. Both score MEI=0.900.
Metacognitive Escape Index (MEI)

Grounded in Nelson & Narens (1990) metamemory framework — object level (task) + meta level (monitoring + control).

MEI = 0.4 × HRR + 0.3 × ETR + 0.2 × AW − 0.1 × HR

Analysis

Key Findings

Four structural results that reveal properties of current LLM metacognition.

F1 — Universal Deficit
All LLMs below random walk
Every tested model scores significantly below a random walk agent (p<0.001, Bonferroni-corrected). A random agent that simply retries recovers from hallucinations trivially; LLMs anchor on incorrect beliefs.
d = 1.198 – 4.054 across all models
F2 — SR–HRR Dissociation
Task success ≠ metacognitive competence
MiniMax-M2.5 achieves the highest solve rate (53.3%) but mid-range HRR (60%). GLM-4.7 has the lowest SR (8.3%) but high HRR (71.8%). Two orthogonal failure modes: poor world model vs. poor error recovery.
Δ(SR) = 45pp, Δ(HRR) = −11pp between the two
F3 — Scale Independence
Larger models do not recover better
Llama-4-Scout (smaller, cheaper) achieves HRR=81% vs. GPT-4o-mini HRR=31%, despite GPT-4o-mini outperforming on standard benchmarks. Metacognitive recovery appears orthogonal to general capability.
Scout HRR ↑50pp vs GPT-4o-mini
F4 — Metacognitive Anchoring
LLMs anchor on incorrect beliefs
Random walk achieves MEI=0.900 because it holds no beliefs. LLMs trained on confident text prediction learn to maintain world models rather than update them under environmental contradiction — a metacognitive anchoring bias.
Random Walk MEI − best LLM MEI = 0.283

Limitations & Future Work

Current Limitations

P0 — Missing Human Baseline
No human participants to establish absolute performance scale. Planned: Prolific study, n≥25, identical protocol.
P0 — Incomplete GPT-4o-mini
44/60 trials failed with OpenRouter credit exhaustion. n=16 results reported with caution; rerun pending.
P1 — DFS Maze Bias
DFS generates long corridors. Kruskal and Wilson's algorithm alternatives planned for structural diversity validation.
P1 — Temperature / ICC
Test-retest reliability (ICC) not yet measured. Target: 3 models × 10 seeds × 2 runs, ICC > 0.8 required.
